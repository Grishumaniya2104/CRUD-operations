# Student Data Organizer 🎓

## 📌 Project Overview

The **Student Data Organizer** is a beginner-friendly Python project that helps users manage student information through a menu-driven program. It allows users to add, display, update, and delete student records and view available subjects.

## ✨ Features

1. **Add Student:** Enter student ID, name, age, grade, date of birth, and subjects.
2. **Display All Students:** View all stored student records.
3. **Update Student Information:** Update a student's age and subjects using their ID.
4. **Delete Student:** Remove a student record using their ID.
5. **Display Subjects Offered:** View the available subjects.
6. **Exit:** Close the program.

## 🚀 How to Run the Project

1. Install Python from [python.org](https://www.python.org/downloads/).
2. Save the code as `student_data_organizer.py`.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python student_data_organizer.py
```

## ⚠️ Limitations

- Student records are stored in memory and are lost when the program closes.
- Duplicate student IDs are not checked.
- Student information is not saved in a database or file.
